# SHEPHERD

Women's Safety Intelligence & Early Response Network.

## Project Structure

- apps/web: Next.js frontend
- services/api: Core FastAPI backend
- services/intelligence: OCR, classification, risk and graph intelligence
- supabase: Database migrations and seed data
- docs: Product, architecture, API and AI documentation

## Development Rules

1. Work only within your assigned folders.
2. Do not change shared API contracts without team approval.
3. Create a pull request for every integration.
4. Run tests before requesting review.
5. Do not commit secrets or real sensitive user evidence.
6. Clearly label mock functionality and demo data.
7. Never claim unverified AI accuracy or emergency dispatch.
